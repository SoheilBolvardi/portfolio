# Soheil Bolvardi — Personal Portfolio

Personal portfolio website showcasing my academic background, teaching experience, technical projects, and skills.

## Live Website

[Visit my portfolio](https://soheilbolvardi.github.io/portfolio/)

## Built With

* JavaScript
* CSS
* HTML
* Vite

## Run Locally

```bash
git clone https://github.com/SoheilBolvardi/portfolio.git
cd portfolio
npm install
npm run dev
```

Open the local URL printed by Vite in your browser.

## Deployment

The website is deployed using GitHub Pages, with automated builds and deployment through GitHub Actions.
